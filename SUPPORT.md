# Support

Need help with one of my projects? Here's where to look — please pick the
channel that fits your situation.

## 📖 Before you ask

1. Read the project's `README.md` and any docs in the repository.
2. Search [existing issues][issues] and [discussions][discussions] — your
   question may already be answered.

## 💬 Questions and usage help

For "how do I…?" questions, general usage help, and ideas, please use
**[GitHub Discussions][discussions]** on the relevant repository. This keeps
answers searchable for the next person with the same question.

## 🐛 Bugs and feature requests

If you have found a reproducible bug or want to request a feature, open an
**[issue][issues]** using the appropriate template. Please include enough detail
for the problem to be reproduced.

## 🔒 Security issues

**Do not** report security vulnerabilities through public issues or discussions.
Follow the process in [SECURITY.md](SECURITY.md) instead.

## ⏱️ Expectations

These are personal, largely volunteer-maintained projects. I try to respond when
I can, but there is no guaranteed response time or SLA. Clear, reproducible
reports and well-scoped pull requests get resolved fastest. Thank you for your
patience and understanding.
